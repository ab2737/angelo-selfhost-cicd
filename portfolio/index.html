Finance project · Planned

What happens to margin when freight costs rise?

In my career research, Gellert Global Group’s Sales Planning Analyst role stood out because it connected import costs to profitability. That finding shaped the question I want my finished-goods model to answer: if the selling price stays the same, how much margin does a higher freight cost take away from each unit?

I plan to compare two freight scenarios in a workbook. The workbook and findings are still in development.

Individual case study · Working prototype

Academic Assistant for NJIT Registrar questions

A student looking for an official transcript needs both an answer and a place to verify it. I built a small assistant that searches three Registrar notes and links each supported answer to its NJIT source.

One question helped me test the limits of the app. The notes explain where to order a transcript, but they do not give a fee. My Review 2 QA checks recorded the ordering question returning REG-1 and the fee question returning an insufficient-information message.

Group case study · Planning stage

Comparing search methods for a shared content system

Our group planned a content system for answering questions from approved sources. We needed a way to tell whether a more complex search method would actually help a reader find better evidence.

Our plan compares keyword search with vector search using test questions. We also included peer review so a teammate can check whether the cited material supports an answer. The links below lead to the project and its written planning evidence.

Academic Assistant

Import three NJIT Registrar notes, then ask about transcripts or semester dates. The app saves the notes in this browser. When you reopen this page on the same site, you can ask another question without importing again. Chat history clears when the page closes or reloads.

Sources and technical evidence

Each note covers one topic. The app converts the question and notes into sets of words, ranks matches using cosine similarity, and returns the matching note when enough words overlap. Different wording can change which answer it finds.

Source and import record

The import button accepts only the three bundled summaries listed here. It does not request a student login, upload a file, or access private student records. Follow the NJIT links to check each summary against its source.
